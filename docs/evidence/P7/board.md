## How to use this board
- **Read it** before you touch anything outside your owned files, and before you rely on another worker's interface.
- **Append** with a single `cat >> /home/kali/Desktop/rag-bot/ragbot-widget/docs/evidence/P7/board.md`. Always use this absolute path, never your worktree's copy.
  - Entry format: `### [<task id>] <YYYY-MM-DD HH:MM> <KIND>: <title>`, then short lines.
  - KIND is `CLAIM`, `INTERFACE`, `QUESTION`, `ANSWER`, `CONFLICT` or `DONE`.
- **Message other workers with `SendMessage`** (find them with `ListAgents`) for anything that blocks you, and also post it here.
- **Claim before you take.** Never edit another worker's files.
- **Contract changes** go through Opus: post a `CONFLICT` and message Opus. Don't work around it.
- Never paste keys, tokens, chat text or document text here.

## Frozen interface 1: migration 013 (`supabase/migrations/013_chat.sql`, owner P7-DB)
All functions:
- service_role only (revoke from public, anon and authenticated).
- SECURITY INVOKER, `set search_path = ''`, `set lock_timeout = '2s'`.
- `schema_version()` returns 13.

Errors:
- RB037: not found or not owned. Never say which.
- 22023: a bad argument.
- RB036: settings missing.

- `get_chat_context(p_bot_id uuid) returns jsonb`, with keys:
  - `bot`: `{id, slug, enabled, display_name, identity_prompt, tone, scope, allowed_languages, embedding_model, embedding_dimensions, settings_version, corpus_version}`. `tone` and `scope` are `''` when null.
  - `settings`: `{feature_flags, handoff_policy}`. Both are jsonb objects, and `{}` is fine.
  - `contact`: `{supported_languages, escalation_label, escalation_messages, email, phone, whatsapp_url, page_url, business_hours, timezone}`, taken from `public_bot_config`. Unset values are null.
  - A missing `client_settings` or `public_bot_config` row raises RB036. A disabled bot is returned with `enabled: false`.
- `start_chat_turn(p_bot_id uuid, p_visitor_session_id uuid, p_run_id uuid, p_conversation_id uuid, p_content text) returns table (conversation_id uuid, user_message_id uuid, prior_no_knowledge integer)`:
  - The run must belong to this bot and session and be `reserved` or `running`, otherwise RB037.
  - `p_conversation_id` null: create an `open` conversation owned by the session. Otherwise the conversation must belong to this bot and session and be `open`, otherwise RB037.
  - `p_content`: 1..2000 characters after trim, otherwise 22023.
  - Inserts the `user` message with `request_id = p_run_id` and sets `last_message_at`.
  - `prior_no_knowledge` counts this conversation's assistant rows with `handoff_reason` in (`no_knowledge`, `repeated_no_knowledge`).
- `finish_chat_turn(p_bot_id uuid, p_visitor_session_id uuid, p_run_id uuid, p_message_id uuid, p_conversation_id uuid, p_user_message_id uuid, p_content text, p_status text, p_provider text, p_model text, p_handoff_reason text, p_sources jsonb) returns void`:
  - Inserts the assistant message with id `p_message_id` (pre-generated by the API so `meta` can carry it), `reply_to_message_id = p_user_message_id` and `request_id = p_run_id`.
  - Checks ownership as above. `p_status` must be in `complete`, `partial`, `failed` or `blocked`. `p_handoff_reason` is null or a `HANDOFF_REASONS` value. `p_content` may be `''`.
  - `p_sources`: a JSON array, at most 20 items, of `{chunk_id, document_version_id, source_label, excerpt, page_number, section}`.
    - Each chunk must exist, belong to that version, and that version's document must belong to this bot. Otherwise 22023, and nothing is inserted.
    - `source_label` is 1..300 characters; `excerpt` up to 500; `section` up to 300.
  - A second call for the same `p_message_id` fails (unique), so it never double-inserts.
- `record_request_usage(p_bot_id uuid, p_run_id uuid, p_provider text, p_model text, p_operation text, p_input_tokens integer, p_output_tokens integer, p_estimated_cost numeric, p_latency_ms integer) returns uuid`:
  - The run must belong to the bot, otherwise RB037.
  - `p_operation` must be `chat`, `embedding_query` or `moderation`.
  - Tokens, cost and latency must be ≥ 0. Writes `usage_events.request_id`.
- `get_conversation_history(p_bot_id uuid, p_visitor_session_id uuid, p_conversation_id uuid, p_before uuid, p_limit integer) returns table (id uuid, role text, content text, status text, handoff_reason text, created_at timestamptz, has_more boolean)`:
  - Ownership as in `start_chat_turn`; a closed conversation may be read.
  - Returns `user` and `assistant` rows only (never `system`), with `p_limit` 1..100.
  - `p_before`: rows older than that message (which must be in the conversation, otherwise RB037). Null: the newest page.
  - Rows come oldest first within the page. `has_more` is the same value on every row.
- `message_sources` gains `page_number integer null` (≥ 1) and `section text null` (B-9 snapshot). Member read access is the same as for the existing columns.
- Analysis enqueue (`analyze_conversation`) is **not** in P7. P9 adds it together with its handler.

## Frozen interface 2: AI adapters (`shared/src/ai/`, owner P7-AI)
Export from `@ragbot/shared/ai`:
- **`createChatProvider(config: ProviderConfig, options?: { fetch?: typeof fetch; requestTimeoutMs?: number }) => ChatProvider`**
  - Implements the shared `ChatProvider` interface for `gemini`, `openai`, `openai_compatible` and `anthropic`.
  - Streams text chunks. The generator's return value is `ChatUsage`.
  - Throws `ProviderError` with kinds and `billed` as in the embedding adapter: `billed: true` after any 2xx.
  - A caller abort is an AbortError. No sampling parameters.
- **`createModerationProvider(config: ModerationConfig, options?: same) => ModerationProvider`**
  - `endpoint` mode: the OpenAI moderations API. `usage` is null.
  - `llm_classifier` mode: a fixed classifier prompt on a chat provider, with a strict one-word reply `ALLOW` or `BLOCK`. Anything else means `block` (fails closed). `usage` is set.
- **`createEmbeddingProvider`** already exists (P6). The API uses it with `taskType: 'query'`.
- **Pricing helper:** `estimateCostUsd(usage: ChatUsage, price: { inputPerMillion: number; outputPerMillion: number }) => number`.
- **Fakes for tests:** `tests/helpers/fake-ai.ts`, labelled FAKE. In-memory fake chat, moderation and embedding providers with scripted replies, failures after N chunks, and abort recording. Both the API unit tests and the e2e tests use them.

## Frozen interface 3: API (`api/`, owner P7-API)
- **Routes:**
  - `POST /v1/chat`: SSE.
  - `GET /v1/conversations/:id?before=<uuid>`: JSON `ConversationHistoryResponse`. Only when `feature_flags.history_enabled` is not `false` (ADR 0009 default on). Disabled gives 403 `FORBIDDEN`.
- **New required API env, fail closed, no defaults:**
  - `RETRIEVAL_TOP_K` (1..50)
  - `RETRIEVAL_MIN_SIMILARITY` (0..1)
  - `CHAT_CONTEXT_MAX_TOKENS`
  - `CHAT_HISTORY_MAX_MESSAGES` (0..50)
  - `CHAT_MAX_OUTPUT_TOKENS`
  - `CHAT_PRICE_INPUT_PER_MILLION` and `CHAT_PRICE_OUTPUT_PER_MILLION`
  - `CHAT_FALLBACK_PRICE_INPUT_PER_MILLION` and `CHAT_FALLBACK_PRICE_OUTPUT_PER_MILLION`, required only when a fallback is configured
  - `MODERATION_PRICE_INPUT_PER_MILLION` and `MODERATION_PRICE_OUTPUT_PER_MILLION`
  - `EMBEDDING_PRICE_PER_MILLION_TOKENS`
  - `CHAT_RESERVATION_TTL_SECONDS`
  - `CHAT_PROVIDER_ATTEMPTS` (1..3, total attempts per provider before the first token)
  - `HISTORY_PAGE_SIZE` (1..100)
  - The existing `CHAT_DEADLINE_MS` bounds the whole request.
- **Per-request order:**
  1. Body schema, Idempotency-Key, bearer token and `bot_slug` match.
  2. Rate limit, then `beginRun`. A replay returns JSON.
  3. `get_chat_context`. A disabled bot gives 403.
  4. Embedding model guard.
  5. Reserve the worst-case budget.
  6. `start_chat_turn`, then mark the run running.
  7. SSE headers and `meta`.
  8. Input moderation in parallel with the query embedding.
  9. Blocked: `blocked` handoff.
  10. Deterministic human-request matcher: `human_requested` handoff.
  11. `match_document_chunks(top_k, min_similarity)`. None: `no_knowledge` handoff, or `repeated_no_knowledge` when `prior_no_knowledge + 1 >= threshold`.
  12. Build the prompt with history from `get_conversation_history`.
  13. LLM with retries and fallback before the first token only.
  14. Hold back the first line until the header is parsed.
  15. Output moderation (`buffer` or `rolling`).
  16. `delta` events, then citations, then `sources`.
  17. A `handoff` when the header says so.
  18. `finish_chat_turn`.
  19. Usage rows for every call.
  20. Settle the budget, finish the run, then `done`.
- **Handoff message:** `escalation_messages[lang]`, then `escalation_messages[supported_languages[0]]`. If neither exists: no handoff message (log `handoff_message_missing`, code only), but still send the event with an empty message.
